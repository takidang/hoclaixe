# Ảnh chụp màn hình app đối thủ (chỉ để tham khảo)

Dùng để: phân tích luồng, hành vi nghiệp vụ (thi thử, chấm điểm, ôn câu sai…) và bố cục khi viết SRS / UX spec.

## Đặt tên file
`<app>_<màn-hình>_<số>.png` — ví dụ:
- `waterfall_home_01.png`
- `waterfall_exam_01.png` (đang làm bài)
- `waterfall_exam-grid_01.png` (lưới số câu)
- `waterfall_result_01.png`
- `waterfall_wrong-review_01.png`
- `waterfall_signs_01.png`

Nên chụp đủ các màn: trang chủ, chọn hạng, học theo chủ đề, đang thi, lưới câu, nộp bài/hết giờ, kết quả,
xem lại bài, ôn câu sai, câu điểm liệt, biển báo, thống kê, cài đặt.

## Lưu ý
- Chỉ tham khảo hành vi và bố cục; **không** sao chép logo, hình ảnh, màu thương hiệu hay văn bản riêng của đối thủ vào app.
- **Không** lấy câu hỏi/đáp án từ ảnh đối thủ làm dữ liệu — dữ liệu chỉ lấy từ nguồn chính thức (csgt.vn), xem `docs/data/sources.md`.
- Repo đang private; ảnh này không đưa vào báo cáo trừ khi ghi rõ nguồn (tên app, ngày chụp).
